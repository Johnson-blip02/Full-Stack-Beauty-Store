# 💄 Beauty Bliss - E-Commerce Web App

A full-stack e-commerce web application for a modern Beauty & Makeup store. Built with a powerful `.NET` backend and a sleek `React` frontend styled using `Tailwind CSS`.

---

## 🧰 Tech Stack

**Frontend**
- React
- Tailwind CSS
- TypeScript

**Backend**
- .NET (ASP.NET Core)
- Entity Framework (if applicable)
- Cookie-based Authentication

---

## 🚀 Features

- 🔐 User Authentication (Sign Up / Log In)
- 🍪 Persistent sessions using cookies
- 🌓 Dark and Light Mode toggle
- 🛍️ Full shopping experience with cart & order saving
- 🔍 Real-time search functionality
- 🎯 Product filters by category, price, etc.
- 🧾 User account order history

---

## 📦 Installation & Running Locally

### 1. backend

```bash
cd API
dotnet run
```

### 2. frontend

```bash
cd client
npm install
npm run dev
```
